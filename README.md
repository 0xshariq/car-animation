# 🚗 Car Animation

A 3D car animation created in Blender as part of my Blender learning journey.

This project focuses on vehicle animation, camera movement, scene optimization, lighting, rendering, and cinematic storytelling.

## 📌 Project Status

✅ Animation Completed

🚧 Rendering In Progress

The animation has been fully completed and tested inside Blender.

The final rendered output is currently being processed and optimized. Once rendering is complete, the final animation will be published in this repository.

## 🎯 Project Overview

This project was created to practice:

* Vehicle Animation
* Follow Path Animation
* Camera Animation
* Scene Optimization
* Lighting Setup
* Rendering Workflow
* Cinematic Storytelling

The animation takes place in a night-time highway environment featuring multiple vehicles, animated camera movement, camera shake effects, and dynamic scene composition.

## 🏆 Project Significance

This is currently my **best Blender project** and the most ambitious project I have completed so far.

Throughout the development process, I learned not only animation techniques but also scene optimization, memory management, rendering workflows, and problem-solving within hardware limitations.

This project marks an important milestone in my Blender learning journey.
