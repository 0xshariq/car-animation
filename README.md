# 🚗 Car Animation

A cinematic 3D car animation created in Blender as part of my Blender learning journey.

This project focuses on vehicle animation, camera movement, scene optimization, lighting, rendering, and cinematic storytelling while working within hardware limitations and optimizing for performance.

## 📌 Project Status

✅ Animation Completed

✅ Rendering Completed

✅ Final Output Published

## 🎯 Project Overview

This project was created to practice:

* Vehicle Animation
* Follow Path Animation
* Camera Animation
* Scene Optimization
* Lighting Setup
* Rendering Workflow
* Cinematic Storytelling

The animation takes place in a night-time highway environment featuring multiple vehicles, cinematic camera movement, camera shake effects, realistic reflections, and dynamic scene composition.
